# SilversHeart

Portfólio pessoal Cassiano Silverston, criado para apresentar minha trajetória, meus conhecimentos e meus projetos em desenvolvimento de software.

Atualmente, direciono meus estudos para backend com C# e .NET. O site reúne projetos que fazem parte dessa jornada e também é uma oportunidade para praticar desenvolvimento web.

## Tecnologias

- HTML para estruturar o conteúdo.
- CSS para a apresentação visual e a responsividade.
- JavaScript para futuras interações.

## Como executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/CassianoSilvers/SilversHeart.git
   ```

2. Abra a pasta `SilversHeart` e, em seguida, abra o arquivo `index.html` no navegador.
